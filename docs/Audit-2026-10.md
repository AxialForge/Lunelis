# Audit - October 2026 (after 0.32)

A security review, a feature-coverage review and an ease-of-use review of
Lunelis 0.30-0.32, read from the code. What each found, and what was done.

Status: **fixed** = in the version named; **later** = kept for a later
version, with the reason. Everything marked 0.33 shipped in 0.33.0.

## Security

| # | Finding | Severity | Status |
|---|---|---|---|
| S1 | Family gallery: Update with an empty PIN field removed the PIN | medium | fixed in 0.31.0 (an empty field keeps it; "Remove the PIN" removes it) |
| S2 | Family gallery: parallel guesses could slip past the 5-try PIN lockout | medium | fixed in 0.31.0 (an attempt is counted before it's checked; one PIN check at a time) |
| S3 | Text from a photo's EXIF (camera, lens) was shown as rich text in the Info panel; a crafted file could carry a link | medium | fixed in 0.33.0 |
| S4 | The updater swaps the whole install folder: a data folder (or other programs) inside it would be removed | medium | fixed in 0.33.0 |
| S5 | Emptying quarantine could fail half-way on a sidecar listed twice (x.xmp / x.XMP), leaving no record | medium-low | fixed in 0.33.0 |
| S6 | Before a permanent delete on a NAS, the kept copy was checked by size only | medium-low | fixed in 0.33.0 |
| S7 | Family gallery: negative Content-Length, no socket timeout, unbounded parallel rendering | low | fixed in 0.31.0 |
| S8 | Family gallery: a PIN change didn't log out earlier visitors | low | fixed in 0.31.0 |
| S9 | Family gallery: original downloads failed for non-Latin file names | low | fixed in 0.31.0 |
| S10 | Quarantine / migration move could fail half-way on a sidecar name clash | low | fixed in 0.33.0 |
| S11 | Update checksum comes from the same place as the download | low (design) | later: signing releases needs a key kept off GitHub; noted |
| S12 | Crafted Takeout JSON / .cube / Sony XML / huge PNG could stop a job or use a lot of memory | low | fixed in 0.33.0 |
| S13 | Autopilot "Undo" of scene tags removed earlier suggestions on re-imported photos | low | fixed in 0.33.0 |
| S14 | Release notes opened any link | low | fixed in 0.33.0 |

Checked and sound: the gallery's address filter, keys, headers, privacy and
escaping; the updater's TLS, verify-before-extract and zip handling; pinned
model downloads; the map (nothing sent until turned on); every SQL query
parameterised; XMP parsing; the never-overwrite rules for outputs, imports,
backups and migration; problem reports (shown, never sent).
